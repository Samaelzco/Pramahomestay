# Audit Log

- Mode: Operate.
- Halaman bersifat read-only dan menampilkan perubahan terbaru lebih dahulu.
- Admin dapat memfilter berdasarkan kata kunci, modul, aktivitas, user, dan rentang tanggal.
- Daftar menjadi tabel pada layar lebar dan data berlabel dua kolom pada tablet/mobile tanpa horizontal scroll.
- Detail aktivitas menampilkan actor, waktu, alamat IP, nilai sebelum/sesudah, dan konteks perangkat.
- Nilai sensitif seperti password dan token tidak pernah disimpan dalam Audit Log.
